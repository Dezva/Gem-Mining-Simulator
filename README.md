# Gem Mining Simulator

Repositorio del proyecto. Los primeros recursos publicados son **prototipos de arte 3D**, no versiones finales del juego.

Consulta la rama `art/picos-3d-prototipos-v1` para descargar los cuatro modelos conceptuales Legendary, Celestial, Supreme y Mythic, su generador en Python y las instrucciones de importación.

No se ha publicado ni modificado ningún lugar de Roblox a través de este repositorio.
